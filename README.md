# random-single-molecule-triggering
Using a Gillespie algorithm to create state sequences which are translated to laser triggering sequences for single-molecule measurements.

## Installation of required Python Libraries
**Gillespie** from [sueskind](https://github.com/sueskind/gillespie) 

Available on [pypi.org](https://pypi.org/project/gillespie/), install via pip:
```bash
pip install gillespie
```
